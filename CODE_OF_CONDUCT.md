# Code of Conduct

ProductWoc contributors are expected to keep project spaces constructive, safe and
focused on the work.

- Treat people with respect regardless of background, identity or experience.
- Critique ideas and changes without personal attacks or harassment.
- Do not publish another person's private information, credentials or project data.
- Accept maintainers' reasonable moderation and security decisions.
- Report harmful conduct privately to the repository owner when public discussion
  would expose a participant or sensitive material.

Maintainers may edit or remove contributions and restrict participation when
behavior threatens people, project security or productive collaboration. They
should explain enforcement decisions when doing so is safe and appropriate.
